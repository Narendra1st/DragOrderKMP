# KMP Drag and Drop App

This is a Kotlin Multiplatform (KMP) app built using Compose Multiplatform.

In this app, you can drag a person item and drop it into the **Person Card Area**.
When you drop a person, their name is automatically added to the card/description.

## Features

* Drag and drop functionality
* Drag a person card
* Drop into person card area
* Name is added automatically
* Works on Android and other KMP targets

## Use Cases

* POS system
* Task assignment
* Team or staff selection
* Order or item tagging

## Tech Stack

* Kotlin Multiplatform
* Compose Multiplatform

## How to Run

1. Open project in Android Studio
2. Sync Gradle
3. Run Android target
4. For desktop, run desktop configuration

## Example Flow

1. Select a person
2. Drag the person card
3. Drop into person card area
4. Person name appears on the card

This project is for learning and demo purposes to understand drag and drop using KMP and Compose.
